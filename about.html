Sign Language Studio is an open, high-performance computer vision platform designed to translate American Sign Language directly on the client edge. Engineered with on-device deep learning, zero cloud ingestion, and real-time WebRTC peer-to-peer rooms.

01 • Computer Vision & Deep Learning

Client-Side Neural Inference

The vision stream tracks 21 articulated 3D hand keypoints at 30 to 60 FPS using MediaPipe Hands. Landmarks are normalized relative to wrist origin and evaluated by a 4-layer Sequential Deep Neural Network in TensorFlow.js. Neural inference executes with ~15-25ms forward passes on WebGL/GPU, driving ~400ms debounced recognition lock-in for sustained gesture confirmation, ensuring video frames never leave the device.

02 • Real-Time Telecommunications

Bidirectional P2P Channels

The platform establishes direct browser-to-browser WebRTC DataChannels using PeerJS. Hearing users can speak naturally via the Web Speech API, with words tokenized and translated into illustrated sign sequences in real time. Deaf users sign directly into the camera, streaming synthesized speech and textual feedback to their partner.

WebRTC PeerJS Web Speech API P2P Rooms
03 • Multimodal Education & Telemetry

Practice Academy & Vision AI

The interactive Practice Laboratory provides pose hold-and-verify feedback, circular SVG progress rings, streak multiplier scoring, and a 60-second speed-run mode. An integrated zero-auth AI gesture assistant allows users to ask questions about ASL, fingerspelling, grammar, and handshape formation with zero authentication or login required.

SVG Hold Engine Session Telemetry Zero-Auth AI
04 • 3D Kinematics & Sign Synthesis

Three.js 3D Text-to-Sign Engine

The 3D avatar studio synthesizes written English and voice dictation into articulated American Sign Language using Three.js and WebGL. Input sentences pass through an offline grammar reordering layer (structuring English into ASL Time-Topic-Comment syntax) and execute smooth hierarchical joint transformations on an anatomical humanoid rig. The engine delivers real-time fingerspelling (A-Z, 0-9) and 35+ whole-word ASL signs with customizable shader themes.

System Feature : Native Windows OS Gesture Controller

The Windows OS Controller module connects real-time computer vision tracking directly to native Windows operating system automation via an ultra-low-latency WebSocket bridge. Native desktop execution is fully functional and operational. Users can steer cursor coordinates across multi-monitor setups, perform left/right/double clicks, drag-and-drop windows and files, scroll documents, adjust master system volume and display brightness, trigger screenshot snipping tools, and virtually inject recognized text sentences into any focused Windows application.

3D Kinematic Synthesis : Text-to-Sign Architecture

The Text-to-Sign studio transforms written English and natural speech into articulated American Sign Language animations on a 3D humanoid mesh in real time. Sentences are parsed by a client-side linguistic reordering engine that restructures English Subject-Verb-Object phrasing into authentic ASL Time-Topic-Comment syntax. Individual signs are animated via hierarchical skeletal joint keyframes covering authentic one-handed fingerspelling (A through Z) and an expandable dictionary of whole-word signs. We acknowledge and credit Sign-Flow (maddyroxx) for architectural reference and inspiration regarding Three.js humanoid rig pipelines and client-side sign animation concepts.
